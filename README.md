# 日韩 11 日行程拖拽规划器

纯静态 GitHub Pages 页面：

- “行程排布”页签支持上午、下午、晚上之间拖动、同栏排序、词条库、回收站撤销及 PNG/JSON 导出。
- PNG 提供 2400×1800 横版总览与竖版明细两种版式；横版采用 4＋4＋3 日历卡和一张出发前检查卡。
- “时间明细”页签按天展示建议开始时间、预计耗时、转场缓冲和待确认航班节点。
- “景点汇总”页签按釜山、福冈、熊本、首尔归类展示计划景点、日期、类型与地区游览提示。
- 当前基线为 2026/9/25–10/5；九州段加入大濠公园、福冈城遗址、LaLaport 实物大 ν 高达、水前寺成趣园、熊本熊广场与阿苏一日备选路线。
- 商业化响应式界面包含旅行路线 Hero、行程统计、吸顶导航、可折叠词条库和城市日程卡，兼顾桌面端与移动端。
- 数据层拆分为 `trip-data.js`（基线与词条）、`trip-content.js`（时间轴与景点内容）和 `trip-store.js`（版本化状态、校验、迁移与持久化）。
- 用户调整结果与自定义词条统一保存在 `jk-trip-planner-state-v1`；首次打开会自动迁移旧版 localStorage，并在过渡期兼容写入旧键，数据不上传服务器。

数据层回归测试：`node tests/trip-store.test.js`
